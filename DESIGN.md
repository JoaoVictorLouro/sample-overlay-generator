# Overlay system

- Background: transparent (these sit on footage)
- Surface: charcoal glass, 12px blur
- Accent: electric cyan for people, magenta for places, amber for notes
- Type: Sora for titles, JetBrains Mono for kickers
- Motion: 12 frames in, hold, 12 frames out
- No drop shadows. Light emits. Corners chamfer, they do not round.

This file is the look. `design-sample/` is a static snapshot of layout. Remotion compositions copy both — they are not a Stitch render target.
